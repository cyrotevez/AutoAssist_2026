Put your downloaded photos in this folder using EXACTLY these names (.jpg):

  welcome_hero.jpg   - big photo for the Welcome screen (portrait, car / road)
  mechanic_1.jpg ... mechanic_6.jpg - photos for mechanic cards (workshop, mechanic at work, tow truck, tyres...)

If a photo is missing the app shows a neutral placeholder, so nothing breaks.
See IMAGES.md in the main folder for search ideas.
